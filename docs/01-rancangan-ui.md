# Rancangan Tampilan & Layout (UI/UX)

## 1. Tema Warna & Styling
- **Primary Color:** Indigo (`#4F46E5`)
- **Secondary Color:** Slate / Neutral Gray (`#64748B`)
- **Background:** Light (`#F8FAFC`) / Dark (`#0F172A`)
- **Framework CSS:** Tailwind CSS (via CDN)

## 2. Struktur Layout Halaman
1. **Header / Navbar:**
   - Brand logo / judul ("Biodata Mahasiswa")
   - Navigasi cepat (Profil, Pendidikan, Hobi, Kontak)
   - Tombol Toggle Mode Gelap / Terang (Dark Mode)

2. **Hero / Profile Section:**
   - Foto profil dengan *border radius* melingkar
   - Nama lengkap & NIM
   - Status mahasiswa aktif (Badge)
   - Tombol "Sapa Saya" (Interaksi JS)

3. **Detail Informasi & Pendidikan:**
   - Card informasi pribadi (Prodi, Fakultas, Email, Alamat)
   - Tabel riwayat pendidikan (SD, SMP, SMA, Perguruan Tinggi)

4. **Keahlian & Hobi:**
   - List hobi dengan ikon visual
   - Progress bar keahlian (HTML, CSS, JS)

5. **Form Kontak & Footer:**
   - Form kirim pesan interaktif
   - Copyright & tautan media sosial
